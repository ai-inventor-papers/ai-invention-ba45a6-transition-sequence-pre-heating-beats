## Layman Summary

Collects months of real motion-sensor logs from four smart homes and turns them into 15-minute per-room occupancy records for testing pre-heating prediction methods.

## Full Summary

Standardized dataset of real, room-level residential occupancy traces built from the WSU CASAS smart-home archive (Zenodo record 17180309), covering four single/few-occupant houses: Aruba (220 days, 31 motion sensors), Cairo (57 days, 27 sensors), Milan (65 days, 28 sensors), and Tulum (235 days, 31 sensors). Raw date/time/sensor-id/ON-OFF event logs were parsed to keep only motion (M-prefixed) sensor ON events, which were binned into 96 fifteen-minute-per-day binary occupancy vectors per (house, day, room). Each example's input is that day's 96-bin occupancy vector for one room; the output is the same vector shifted one bin ahead (a next-bin-occupied forecasting target), matching the granularity PreHeat's per-room K-NN Hamming-distance predictor needs. Room-to-room transitions were reconstructed from consecutive motion events within a day and are attached per example (capped at 40 per row to bound size), giving (from_room, to_room, time-of-day, dwell_minutes) tuples usable for a room-transition model. Because no machine-readable floorplan was available, an adjacency graph per house was inferred from transition co-occurrence frequency (edges kept when observed >=3 times) and is stored in top-level metadata.per_dataset_meta, explicitly flagged as adjacency_provenance='inferred_from_transition_frequency' rather than floorplan-verified. Each example also carries metadata_weekday_weekend (real calendar-derived weekday/weekend split, supporting PreHeat's K=5 nearest-similar-day matching), metadata_house_id, metadata_room_id, metadata_day_id, metadata_real_or_synthetic='real', and metadata_task_type='binary_sequence_forecasting'. All 15,615 examples across the 4 datasets validate against the exp_sel_data_out.json schema. A 5th real candidate (SPHERE Challenge, 9 PIR-sensed rooms) was acquired and evaluated but dropped from the final artifact: its 10 sequences are short scripted lab recordings with no real calendar dates, so weekday/weekend and multi-day K-NN matching are not meaningful there. Total output is 35MB (well under the 300MB dataset budget and 100MB per-file limit), reproducible via data.py which reads the pre-parsed temp/datasets/full_casas_*.json house files and regenerates full/mini/preview JSON in one pass.
